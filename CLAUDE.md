# Instructions for AI assistants

## Git commits

* Commits are the owner's own work. Never add `Co-Authored-By` trailers, `Claude-Session` links, "Generated with" lines or any other mention of Claude or Anthropic to commit messages or pull request descriptions.
* Author commits as the repository owner (`GIOVESS`), not as an assistant.
* Write the message as if the owner committed the code: short imperative subject, optional body.
